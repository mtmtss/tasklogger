# タスク時間記録アプリ 仕様書

## 1. アプリの目的

本アプリは、Google Tasks に登録されているタスクのうち、「今日やるべきタスク」をアプリ上に表示し、各タスクの作業開始・中断・完了を記録するためのタスク管理アプリである。

ユーザーは、タスクごとに実際にかかった作業時間を記録できる。記録されたログは Google スプレッドシートに蓄積され、後からタスクリスト別・タスク別に作業時間を分析できるようにする。

---

# 2. 主な利用イメージ

1. ユーザーがアプリを開く。
2. Google Tasks から、期限が「今日」に設定されているタスクを取得する。
3. アプリ上に「今日やるリスト」として表示する。
4. ユーザーが任意のタスクの「開始」ボタンを押す。
5. アプリが開始時刻を記録する。
6. 作業が終わった場合は「完了」ボタンを押す。
7. 作業を途中で止める場合は「中断」ボタンを押す。
8. 開始から完了、または開始から中断までの経過時間を計算する。
9. 作業ログを Google スプレッドシートに追記する。
10. 後からアプリ上で、タスクリスト別・タスク別の作業時間を確認できる。

---

# 3. 対象データ

## 3.1 Google Tasks 側のデータ

Google Tasks に存在する複数のタスクリストを対象とする。

取得対象は以下の条件を満たすタスクとする。

* タスクの期限日が今日である
* 未完了のタスクである
* Google Tasks 上の任意のタスクリストに属している

表示時には、最低限以下の情報を取得する。

| 項目           | 内容                      |
| ------------ | ----------------------- |
| taskListId   | Google Tasks のタスクリスト ID |
| taskListName | タスクリスト名                 |
| taskId       | Google Tasks のタスク ID    |
| taskTitle    | タスク名                    |
| dueDate      | タスクの期限日                 |
| status       | タスクの状態                  |

---

# 4. 主要機能

## 4.1 今日やるリスト表示機能

Google Tasks から、今日が期限の未完了タスクを取得し、アプリ上に一覧表示する。

### 表示項目

各タスクには以下を表示する。

| 表示項目      | 内容                   |
| --------- | -------------------- |
| タスクリスト名   | 例：仕事、勉強、家事など         |
| タスク名      | Google Tasks のタスク名   |
| 状態        | 未開始、作業中、中断中、完了       |
| 本日の累計作業時間 | そのタスクに対して今日記録された合計時間 |
| 操作ボタン     | 開始、中断、完了             |

---

## 4.2 タスク開始機能

ユーザーが「開始」ボタンを押すと、そのタスクの作業を開始する。

### 開始時の処理

* 現在時刻を `startTime` として記録する
* タスクの状態を「作業中」に変更する
* 同時に作業中にできるタスクは原則 1 件のみとする

### 補足仕様

すでに別のタスクが作業中の場合、新しいタスクを開始しようとしたら、以下のどちらかの動作にする。

推奨仕様：

* 「現在作業中のタスクがあります。先に中断または完了してください」と表示する
* 新しいタスクは開始しない

---

## 4.3 タスク中断機能

ユーザーが作業中のタスクに対して「中断」ボタンを押すと、その時点までの作業時間を記録する。

### 中断時の処理

* 現在時刻を `endTime` として記録する
* `endTime - startTime` により作業時間を算出する
* ログ種別を `paused` として Google スプレッドシートに記録する
* タスクの状態を「中断中」または「未開始」に戻す
* Google Tasks 上のタスク自体は完了にしない

### 用途

タスクがまだ終わっていないが、途中まで作業した時間を記録したい場合に使う。

---

## 4.4 タスク完了機能

ユーザーが作業中のタスクに対して「完了」ボタンを押すと、その作業を完了として記録する。

### 完了時の処理

* 現在時刻を `endTime` として記録する
* `endTime - startTime` により作業時間を算出する
* ログ種別を `completed` として Google スプレッドシートに記録する
* Google Tasks 上の該当タスクを完了状態に更新する
* アプリ上の「今日やるリスト」から非表示、または完了済み表示にする

---

# 5. タスクの状態管理

アプリ内では、タスクに以下の状態を持たせる。

| 状態  | 説明                 |
| --- | ------------------ |
| 未開始 | まだ今日作業を開始していない     |
| 作業中 | 現在タイマーが動いている       |
| 中断中 | 過去に作業したが、まだ完了していない |
| 完了  | 作業が完了した            |

## 状態遷移

```text
未開始
  ↓ 開始
作業中
  ↓ 中断
中断中
  ↓ 再開
作業中
  ↓ 完了
完了
```

または、

```text
未開始
  ↓ 開始
作業中
  ↓ 完了
完了
```

---

# 6. 作業ログ仕様

作業ログは Google スプレッドシートに追記形式で保存する。

1 回の開始〜中断、または開始〜完了を 1 行のログとして記録する。

## 6.1 スプレッドシートのカラム定義

| カラム名            | 内容                       |
| --------------- | ------------------------ |
| logId           | ログの一意な ID                |
| userId          | ユーザー識別子                  |
| taskListId      | Google Tasks のタスクリスト ID  |
| taskListName    | タスクリスト名                  |
| taskId          | Google Tasks のタスク ID     |
| taskTitle       | タスク名                     |
| actionType      | `paused` または `completed` |
| startTime       | 作業開始日時                   |
| endTime         | 作業終了日時                   |
| durationSeconds | 作業時間 秒                   |
| durationMinutes | 作業時間 分                   |
| logDate         | ログの日付                    |
| memo            | 任意メモ                     |
| createdAt       | ログ作成日時                   |

## 6.2 ログ例

| logId   | taskListName | taskTitle | actionType | startTime        | endTime          | durationMinutes |
| ------- | ------------ | --------- | ---------- | ---------------- | ---------------- | --------------- |
| log_001 | 仕事           | 提案資料作成    | paused     | 2026-05-31 09:00 | 2026-05-31 09:45 | 45              |
| log_002 | 仕事           | 提案資料作成    | completed  | 2026-05-31 13:00 | 2026-05-31 13:30 | 30              |

この場合、「提案資料作成」の合計作業時間は 75 分となる。

# 7. 分析機能

アプリ上で、蓄積されたログをもとに作業時間を確認できるようにする。

## 7.1 タスクリスト別集計

タスクリスト単位で、どれくらい時間を使ったかを表示する。

例：

| タスクリスト | 合計時間  |
| ------ | ----- |
| 仕事     | 320 分 |
| 勉強     | 120 分 |
| 家事     | 45 分  |

## 7.2 タスク別集計

タスク単位で、どれくらい時間を使ったかを表示する。

例：

| タスク名   | タスクリスト | 合計時間 | 作業回数 |
| ------ | ------ | ---- | ---- |
| 提案資料作成 | 仕事     | 75 分 | 2 回  |
| 英語学習   | 勉強     | 60 分 | 1 回  |

## 7.3 期間フィルター

分析画面では、以下の期間で絞り込みできるようにする。

* 今日
* 昨日
* 今週
* 今月
* 任意期間

## 7.4 表示形式

最低限、以下の表示に対応する。

* 表形式
* タスクリスト別の合計時間
* タスク別の合計時間
* 日別の作業時間推移

可能であれば、グラフ表示も追加する。

# 9. Google Tasks 連携仕様

## 9.1 必要な操作

Google Tasks API を利用して以下を行う。

* タスクリスト一覧の取得
* 各タスクリスト内のタスク取得
* 今日が期限のタスク抽出
* タスク完了時に Google Tasks 側のステータスを完了に更新

## 9.2 今日の判定

タスクの期限日 `due` が、ユーザーのローカル日付における今日と一致する場合、「今日やるリスト」に表示する。

タイムゾーンはアプリの設定で明示する。

推奨：

```text
Asia/Tokyo
```

---

# 10. Google スプレッドシート連携仕様

## 10.1 必要な操作

Google Sheets API を利用して以下を行う。

* ログ保存用スプレッドシートの作成、または既存シートの利用
* 作業ログの追記
* 分析用データの読み取り
* タスクリスト別・タスク別の集計

## 10.2 シート構成

推奨シート構成は以下。

```text
Spreadsheet
├── logs
├── settings
└── summaries
```

### logs

実際の作業ログを保存するメインシート。

### settings

アプリ設定を保存するシート。

例：

| key                       | value      |
| ------------------------- | ---------- |
| timezone                  | Asia/Tokyo |
| allowMultipleRunningTasks | false      |

### summaries

必要に応じて集計結果を保存するシート。

ただし、集計はアプリ側で都度計算してもよい。

# 11. エラーハンドリング

## 11.1 Google Tasks 取得失敗

Google Tasks からデータを取得できない場合は、以下を表示する。

```text
Google Tasks からタスクを取得できませんでした。接続状態または認証状態を確認してください。
```

## 11.2 スプレッドシート保存失敗

ログ保存に失敗した場合は、ユーザーに通知する。

```text
作業ログの保存に失敗しました。再試行してください。
```

可能であれば、ローカルに一時保存し、後で再送信する。

## 11.3 作業中タスクがある状態で別タスクを開始した場合

```text
現在作業中のタスクがあります。先に中断または完了してください。
```

## 11.4 開始時刻がない状態で中断・完了された場合

不正な状態として処理し、ログは作成しない。

```text
開始時刻が見つからないため、作業時間を記録できません。
```

# 12. 追加した方がよい仕様

## 12.1 再開機能

中断したタスクは、再び「開始」または「再開」できるようにする。

再開した場合は、新しいログとして記録する。

例：

```text
09:00 - 09:30 中断
10:00 - 10:45 完了
```

この場合、ログは 2 行作成され、合計作業時間は 75 分となる。

---

## 12.2 メモ機能

中断または完了時に、任意でメモを入力できるようにする。

例：

```text
途中まで調査完了。次回は資料作成から再開。
```

メモはスプレッドシートの `memo` カラムに保存する。

---

## 12.3 手動同期ボタン

Google Tasks の内容が変更された場合に備えて、手動更新ボタンを用意する。

```text
Google Tasks と同期
```

---

## 12.4 ローカル一時保存

通信エラーや Sheets API の失敗に備えて、未送信ログを一時保存する。

再接続時に自動で Google スプレッドシートへ追記する。

---

## 12.5 重複ログ防止

同じ開始時刻・終了時刻・タスク ID のログが重複して保存されないようにする。

`logId` を UUID などで生成し、同じ `logId` は二重保存しない。

---

## 12.6 日付変更時の処理

深夜をまたいで作業した場合の扱いを決める。

推奨仕様：

* `startTime` の日付を `logDate` とする
* duration は開始から終了までの実時間で計算する
* 分析時には `logDate` 基準で集計する

---

# 13. 非機能要件

## 13.1 認証

Google Tasks API と Google Sheets API を利用するため、Google アカウント認証を行う。

必要な権限：

* Google Tasks の読み取り
* Google Tasks の更新
* Google Sheets の読み取り
* Google Sheets の書き込み

## 13.2 タイムゾーン

日時処理は必ずタイムゾーンを考慮する。

初期設定は以下。

```text
Asia/Tokyo
```

## 13.3 データの一貫性

* 作業ログは原則として削除しない
* 修正が必要な場合は、修正用の管理機能を別途用意する
* Google Tasks のタスク名が後から変更されても、ログには当時の `taskTitle` を保存する

## 13.4 パフォーマンス

今日のタスク一覧表示は、数十件程度のタスクを想定する。

ログは数千行以上になる可能性があるため、分析時には必要に応じて期間で絞り込む。

# 17. 実装上の重要ルール

AI エージェントは、以下のルールを守って実装すること。

1. 作業時間は、開始ボタンを押した時刻と中断・完了ボタンを押した時刻の差分で計算する。
2. 中断時も必ずログを保存する。
3. 完了時も必ずログを保存する。
4. 中断時は Google Tasks 側のタスクを完了にしない。
5. 完了時のみ Google Tasks 側のタスクを完了にする。
6. 1 つの作業ログは、1 回の開始から中断・完了までを表す。
7. 同じタスクに複数回取り組んだ場合は、複数行のログとして保存する。
8. 分析時は、同じ `taskId` または `taskListId` を持つログを集計する。
9. ログには Google Tasks の ID と名称の両方を保存する。
10. 日時は ISO 形式で保存し、表示時にユーザー向けの形式へ変換する。

# 18. まとめ

このアプリは、Google Tasks を「やることリスト」として使いながら、実際にどれだけ時間を使ったかを Google スプレッドシートに記録する時間管理アプリである。

中心となる機能は以下の 3 つ。

```text
Google Tasks から今日のタスクを取得する
作業開始・中断・完了を記録する
Google Sheets にログを蓄積し、後から分析する
```

MVP では、まず「今日やるリスト」「開始・中断・完了」「スプレッドシートへのログ保存」「簡単な集計表示」までを実装する。
その後、グラフ化、週次レポート、AI 分析、予定時間との差分分析などを追加していく。
